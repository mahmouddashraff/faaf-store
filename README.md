# FAAF Fitness Magic — Local Store Starter

This is the first local frontend version of the FAAF Fitness Magic store.

## 1. Install Node.js
Install Node.js LTS from https://nodejs.org/.

## 2. Open this folder in VS Code
Open `faaf-store`.

## 3. Install dependencies
Run:

```bash
npm install
```

## 4. Start locally

```bash
npm run dev
```

Open http://localhost:3000

Shop page: http://localhost:3000/shop

## What is included
- FAAF Fitness Magic branding
- Responsive header/menu
- Homepage
- Shop Products page with two-column mobile layout
- Product cards with rating, option selector, quantity and Add to Cart UI
- Newsletter subscription UI
- Mobile responsive design
